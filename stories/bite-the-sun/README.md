# BITE THE SUN

A tiny 45-second browser game about eating daylight.

## Play

```bash
cd stories/bite-the-sun
python3 -m http.server 4173
```

Open <http://localhost:4173>.

- Move with the mouse, touch, WASD, or arrow keys.
- Eat the gold suns.
- Dodge the white-hot shards.
- Click, tap, or press Space when the chomp meter is full.

Everything is contained in `index.html`; there are no dependencies or network requests.
