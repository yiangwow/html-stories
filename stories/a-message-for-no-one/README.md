# A MESSAGE FOR NO ONE

A private audiovisual transmission instrument. Give it one sentence; it turns that sentence into eighteen seconds of deterministic sound and image.

Open `index.html` directly, or serve it locally:

```bash
cd stories/a-message-for-no-one
python3 -m http.server 4175
```

Then open <http://localhost:4175>.

The sentence stays inside the open page. There are no dependencies, network requests, analytics, or saved data.
