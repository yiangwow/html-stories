# THE BUTTON IS LYING

A tiny escalation toy about an untrustworthy industrial button.

Open `index.html` directly, or serve it locally:

```bash
cd stories/the-button-is-lying
python3 -m http.server 4174
```

Then open <http://localhost:4174>.

- Click or tap the red button.
- Enter and Space also press it.
- Press R to reset the evidence.

Everything lives in one HTML file with no dependencies or network requests.
