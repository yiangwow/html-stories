# ROOM//NULL

An ambient low-resolution room broadcast.

Open `index.html` directly, or serve it locally:

```bash
cd stories/room-null
python3 -m http.server 4177
```

Then open <http://localhost:4177>.

- Move or drag to tune the room.
- Click or tap to change channel.
- Hold the pointer or Shift to stabilize the signal.
- Use Left/Right or Space to change channel.
- Press M to mute.

Everything is generated locally. There are no dependencies, network requests, analytics, or saved data.
