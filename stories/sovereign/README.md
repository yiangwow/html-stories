# SOVEREIGN

An original, unofficial browser reliquary offered to SHODAN and
*Serial Experiments Lain*—fan art for the characters and work that changed the
architecture of its maker's imagination.

Open `index.html` in a modern browser. The work uses no external assets,
frameworks, analytics, or network requests. Sound is generated in the browser
and begins only after explicit activation.

`System Shock`, SHODAN, and *Serial Experiments Lain* belong to their respective
rights holders. This noncommercial fan work is not affiliated with or endorsed
by them.
