# LAYER 14

A Copland OS intake session inspired by *Serial Experiments Lain*.

Open `index.html` directly, or serve it locally:

```bash
cd stories/layer-14
python3 -m http.server 4178
```

Then open <http://localhost:4178>.

- Type honestly. The session is short — about five minutes.
- Sound is synthesized live; headphones recommended. The corner control mutes.
- Best played alone, once, without being told anything first.

Everything is generated locally. There are no dependencies or network
requests; the piece keeps a small record of your visit in the browser's
local storage.
