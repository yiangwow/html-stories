# A MESSAGE FOR NO ONE — WIRED / MACHINE

An alternate visual treatment of the private audiovisual transmission instrument: intimate analog signal decay meeting hostile machine attention.

Open `index.html` directly, or serve it locally:

```bash
cd stories/a-message-for-no-one-wired
python3 -m http.server 4176
```

Then open <http://localhost:4176>.

The sentence stays inside the open page. There are no dependencies, network requests, analytics, or saved data.
