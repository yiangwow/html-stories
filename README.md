# HTML Stories

A collection of eight self-contained browser stories and interactive web works.
Each work lives in its own folder and can be opened directly in a modern
browser.

## Works

1. [KEPT](stories/kept/) — a cleanup shift; forgetting is free, remembering costs
2. [LAYER 14](stories/layer-14/) — a NAVI intake session that learns your keys
3. [SOVEREIGN](stories/sovereign/) — an offering to SHODAN and *Serial Experiments Lain*
4. [ROOM NULL](stories/room-null/) — an ambient broadcast
5. [BITE THE SUN](stories/bite-the-sun/) — 45 seconds of bad astronomy
6. [A MESSAGE FOR NO ONE — WIRED](stories/a-message-for-no-one-wired/) — a wired machine variant
7. [A MESSAGE FOR NO ONE](stories/a-message-for-no-one/) — a private transmission instrument
8. [THE BUTTON IS LYING](stories/the-button-is-lying/) — unnecessary machinery

Open `index.html` for the collection entrance, or open any work's `index.html`
directly.

## Running locally

The works have no build step. From the repository root:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
